# Car details spec (schema v2)

Generated by `python3 tools/art/details.py --doc`; do not edit by hand.

Each car has one file, `docs/cars/details/<id>.json`, checked with
`python3 tools/art/details.py <file> [--dossier <json>] [--strict]`.

Every entry in `parts` is an object with `kind` (one of the kinds below) plus
that kind's fields. Every part also accepts `side` (both, near, far or centre;
default both when lat is above 0, else centre, unless the table gives another
default) and `note` (free text, ignored).

## Top-level fields

- `version`: Must be 2.
- `id`: Game id, the same as the file name without .json and the dossier id.
- `belt_y`: Height of the window sill (belt) line, in car units. Required by --strict.
- `window_frame`: chrome, black or paint. Default chrome.
- `caricature`: Object with eyes, mouth, wheels, bumper, each 0.8 to 1.4 (default 1.0): size multipliers.
- `wheel`: Object: style (steel, wire, knockoff, alloy, disc, spoked), hub (chrome, paint, black), whitewall (bool), trim_ring (bool), hubcap_r (number), spokes (int). Required by --strict.
- `paint`: Object: colour2 (#rrggbb, the one second paint colour), finish (solid or metallic, default solid), zones (list of {region, y, y2, x0, x1, w, use}). A zone with use paint2 needs colour2.
- `roof`: Object: variant (hard, soft_up, soft_down, targa, open, vinyl; default hard), colour (#rrggbb), fold_x0, fold_x1.
- `windows`: List of glass polygons, each a list of at least 3 [x,y] points, side view. Required by --strict (at least 2, unless the roof is open or soft_down).
- `pillars`: List of {poly: [[x,y], ...], lat_from: 0 to 1 (fraction of half width)}.
- `cockpit`: Object: x0, x1, floor_y, seat (#rrggbb), dash (#rrggbb). Open cars only (roof variant open).
- `parts`: List of part objects. Each has kind plus the fields of that kind (see the table above).

## Checks

- Default check: schema, kinds, required fields, enums, numbers, sides, zone colours.
- `--dossier <json>`: |x| <= 51; 0 <= y <= height units + 1; |lat| <= plan.width_units/2 + 1;
  belt_y between 0.35 and 0.95 of height units; window and shutline points inside the car;
  bumper, plate and grille at the front need x >= 40 and at the rear x <= -40.
- `--strict`: at least 24 parts; a headlamp, a taillamp, front and rear bumper, front and rear
  plate, an exhaust, a wheel object and belt_y; at least 3 badge, handle, strip, crease or
  shutline parts; with a dossier, shutline count >= 2 x doors + 2 for cars without an open roof;
  at least 2 window polygons unless the roof is open or soft_down.
