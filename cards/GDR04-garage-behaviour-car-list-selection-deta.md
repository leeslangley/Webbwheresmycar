## Steps
1. Edit `godot/scenes/garage.gd` (keep GDR03's content). Add members `var sel_id := ""`, `var page := 0`, `var _rows: Array = []`. In `_ready`, after the art call `_build_controls()`, `_connect_game()`, `refresh()`. `_build_controls()` uses `RoomButton.add_to(self, id, rect, text, kind)` (GDR25): `&"back"` R_BACK "BACK"; `&"page_up"` R_PAGE_UP "UP"; `&"page_down"` R_PAGE_DOWN "DOWN"; and five row buttons `&"row0"`..`&"row4"` at `row_rect(i)` with `align_left = true`, `font_kind = "body"`, `font_px = 24` (collect them in `_rows`).
2. Data helpers: `func state() -> Dictionary` (= `get_game().state`), `func cars() -> Array` (= `state().cars`), `func selected_car() -> Dictionary` (the car whose `id == sel_id`, or `{}`), `func row_car_ids() -> Array` (the ids on the current page: `cars()[page * 5 .. page * 5 + 4]`). `func page_count() -> int` = `maxi(1, ceili(cars().size() / 5.0))`. `func select(car_id: String)`: set `sel_id`, set `page` to the page that holds it, `refresh()`. `func page_move(delta: int)`: `page = clampi(page + delta, 0, page_count() - 1)`, `refresh()`. `func enter(params: Dictionary = {})`: `sel_id = String(params.get("carId", ""))`; if that id is not a car, `sel_id` = the first car's id (or ""); then `refresh()`.
3. `func refresh() -> void`: keep `sel_id` valid (first car when the old one vanished, "" when no cars) and `page` in range. List: for row `i` in 0..4, if `i < row_car_ids().size()` the button is visible and enabled, `selected = (car id == sel_id)`, text = model name + "\n" + ("OWN" or "RENT") + "  COND " + `CoreFormat.one_dp(condition)` + ("  FAULT" if `fault != null`) + ("  IMPOUNDED" if `impoundedUntil > state.day`); otherwise the button is `visible = false` and `enabled = false`. `StableLabel.text = "STABLE %d/%d" % [cars().size(), state().garageSlots]`; `EmptyLabel.visible = cars().is_empty()`; `page_up`/`page_down` buttons are dimmed (`set_dimmed`) at the first / last page. Detail (all labels are `Ui/<name>` from GDR03; model = `GarageCosts.model_of(car.modelId)` if GDR26 is merged, else a local loop over `Data.cars()`): `NameLabel` = model name, `QuipLabel` = model quip, `DesLabel` = "DESIRABILITY " + one_dp(`SimCarStats.eff_d(model, car)`), `RelLabel` = "RELIABILITY " + one_dp(`SimCarStats.eff_r(model, car)`), `CondLabel` = "CONDITION " + one_dp(condition); the three fills get `size.x = BAR_W * clampf(value / 10.0, 0.0, 1.0)`; the condition fill colour is `#3FAE49` when condition >= 7, `#FFD27A` when >= 4, else `#D9483B`; `ValueLabel` = "Value " + `CoreFormat.money(SimCarStats.market_value(state, model, car))`; `CostLabel` = "Running cost/month " + money(`SimCarStats.running_cost(model, car)`) for an owned car, else "Rent/month " + money(`car.rentMonthly`); `FaultLabel` = "FAULT: " + fault.label + " (fix " + money(fault.cost) + ")" or "". With no car selected all those texts are "" and the bars have width 0. Finish with `_refresh_buttons()`, an empty virtual (`func _refresh_buttons() -> void: pass`) that GDR27 overrides.
4. Input: override `_on_hotspot(id)`: `back` -> emit `request_scene(&"office", {})`; `page_up` / `page_down` -> `page_move(-1 / 1)`; `row0`..`row4` -> `select(row_car_ids()[i])`; anything else -> `_on_action(id)`, an empty virtual (`func _on_action(_id: StringName) -> void: pass`) for GDR27. `handle_key(keycode: int) -> bool`: KEY_UP selects the previous car, KEY_DOWN the next (no wrap), KEY_ESCAPE emits the back request; true when handled. `_unhandled_key_input` forwards pressed `InputEventKey` when visible. `_connect_game()`: connect `get_game().changed` to `refresh` (disconnect in `_exit_tree`).
5. `godot/tests/test_garage_behaviour.gd` with `FakeGame` (game set before adding to the tree): after `enter({})`: `sel_id == "c1"`, `Row0` text contains "Austen Allergy", "OWN" and "COND 5.0"; `Row1` text contains "RENT" and "FAULT"; rows 2..4 are not visible; `StableLabel.text == "STABLE 2/3"`; `NameLabel.text == "Austen Allergy"`; `QuipLabel.text` equals that model's quip from `Data.cars()`. Tapping row1 (`press()` then `release(true)` on `room.hotspots[&"row1"]`) selects c2: NameLabel "Reliable Robbin", FaultLabel starts with "FAULT: Dodgy clutch" and contains `CoreFormat.money(300)`, CostLabel equals "Rent/month " + `CoreFormat.money(260)`; for c1 CostLabel starts with "Running cost/month ". DesLabel for c1 equals "DESIRABILITY " + `CoreFormat.one_dp(SimCarStats.eff_d(model, car))`; the DesBar width equals `290 * clampf(eff_d / 10, 0, 1)` (use `near`). Condition fill colour: 5.0 -> `Color("FFD27A")`, set 8.0 + `refresh()` -> `Color("3FAE49")`, 3.0 -> `Color("D9483B")`. Paging: append five more cars (ids c3..c7, modelId "t1_allergy", owned true, same keys as car1) so there are 7: `page_count() == 2`; `page_move(1)` -> `row_car_ids() == ["c6", "c7"]`, `Row0` text for c6, another `page_move(1)` stays on page 1, `select("c1")` returns to page 0. Keys: `handle_key(KEY_DOWN)` moves the selection c1 -> c2 and a second `KEY_DOWN` leaves it on c2 (no wrap); `handle_key(KEY_UP)` moves back to c1. BACK tap emits `[&"office", {}]`; `handle_key(KEY_ESCAPE)` also. Empty garage (`cars = []`): EmptyLabel visible, NameLabel "", `StableLabel.text == "STABLE 0/3"`. `enter({"carId": "c2"})` selects c2. Changing `fake.state.cars[0].condition` and `fake.changed.emit()` updates CondLabel. Free the node.
