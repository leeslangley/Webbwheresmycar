## Steps
1. Edit `godot/scenes/garage.gd`. In `_build_controls()` add the six buttons with `add_button(id, BTN_RECTS[id], "", "normal")` for ids `&"tinker"`, `&"service"`, `&"fix"`, `&"restore"`, `&"sell"`, `&"consign"`. Implement `_refresh_buttons()` (override the empty virtual, called at the end of `refresh()`): with no selected car all six are `visible = false, enabled = false`; otherwise they are visible and (`c` = selected car, `m` = model, `cash` = state cash, `fc` = fault cost or 0, `consigned` = `GarageCosts.is_consigned(state, c.id)`; "greyed" means `enabled = false`, which UiButton draws grey and answers with its `blocked` signal): `tinker` text "TINKER " + `CoreFormat.money(GarageCosts.tinker_cost(m))`, enabled only if `c.condition < 10 and cash >= tinker_cost`; `service` text "SERVICE " + money(service_cost), same rule; `fix` text "FIX FAULT " + money(fc) when there is a fault else "FIX FAULT", enabled only if `fault != null and cash >= fc`; `restore` text "RESTORE " + money(restore_cost), enabled only if not `(c.condition >= 10 and fault == null)` and `cash >= restore_cost`. Owned car: `sell` text "SELL " + money(`GarageCosts.dealer_price`), enabled only when not consigned; `consign` text "WITHDRAW" if consigned else "CONSIGN", enabled only when (consigned or not an auction day). Rented car: `sell` text "RETURN " + money(`GarageCosts.damage_fee`), enabled only if `cash >= fee`; `consign` is `visible = false, enabled = false`.
2. Actions in `_on_action(id)` (reached from a normal tap through `_on_hotspot`'s fallthrough AND from a tap on a greyed button through `_on_button_blocked`) with `func _act(action: String, params: Dictionary) -> Dictionary`: `var r = get_game().act(action, params)`; call `refresh()`; return `r` (or `{}` when it is not a Dictionary). Do NOT toast refusals (the Game does). `tinker` -> `_act("service_car", {"carId": id, "kind": "quick"})`; `service` -> kind "full"; `fix` -> `"fix_fault"`; `restore` -> `"restore_car"`; `sell` -> `"sell_to_dealer"` for an owned car or `"return_rental"` for a rented one (both `{"carId": id}`); `consign`: if consigned -> `_act("unconsign", {"carId": id})`; else if it is an auction day (`CoreClock.is_auction_day(state.day)`) emit `toast("Too late, the auction is today")`; else `var reserve := GarageCosts.consign_reserve(state, m, c)`, `var r = _act("consign_car", {"carId": id, "reserve": reserve})` and when `r.get("ok", false)` emit `toast("Consigned. Reserve " + CoreFormat.money(reserve))`.
3. Keys: extend `handle_key`: KEY_S = service (full), KEY_T = tinker (quick), KEY_F = fix; each only when a car is selected.
4. `godot/tests/test_garage_actions.gd` with `TestFakeGame` (cash 12345, day 12): select c1 (owned, cond 6.0): button texts equal "TINKER " + money(tinker_cost) etc.; `tinker.enabled == true`; `fix.enabled == false` (no fault) but `TapUtil.tap(fix)` still calls `{"action": "fix_fault", "params": {"carId": "c1"}}` (via `blocked`); tapping tinker gives `fake.acts.back() == {"action": "service_car", "params": {"carId": "c1", "kind": "quick"}}`, service gives kind "full", restore gives `restore_car`, sell gives `sell_to_dealer`; `sell.text` starts with "SELL "; with `fake.next_result = {"ok": false, "msg": "Not enough money"}` a tap leaves `fake.toasts == ["Not enough money"]` and the room emits no toast of its own. Cash 10 -> tinker, service, restore `enabled == false`. Reserve "; after adding `{"carId": "c1", "reserve": 100}` to `state.auction.consigned` + `refresh()` the text is "WITHDRAW" and a tap calls `unconsign`; on day 24 (consigned list empty) CONSIGN is greyed, a tap emits the toast "Too late, the auction is today" and makes no call. `handle_key(KEY_S)` calls `service_car` full.
