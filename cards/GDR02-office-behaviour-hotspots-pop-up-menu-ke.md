## Steps
1. Edit `godot/scenes/office.gd` (keep GDR01's constants and `_ready` start). Add `signal news_closed`, `var menu: UiMenu`, `var _chat_day := -1`, `var _news_open := false`, `const MENU_ITEMS: Array[String] = ["GARAGE", "AUCTION", "NEXT DAY", "SETTINGS"]`. At the end of `_ready` call `_build_hotspots()`, `_build_menu()`, `_setup_tv()`, `_connect_game()`, `refresh()`. `_build_hotspots()` uses `add_hotspot(id, rect)` for exactly: `&"garage_door"` R_GARAGE_DOOR, `&"poster"` R_POSTER, `&"calendar"` R_CALENDAR, `&"phone"` R_PHONE, `&"newspaper"` R_NEWSPAPER, `&"kettle"` R_KETTLE. (No TV hotspot: the TV owns its own remote buttons.) Override `_on_hotspot(id)` with a `match`: garage_door -> `go_garage()`, poster -> `go_auction()`, calendar -> the calendar toast, phone -> `show_channel("bookings")`, newspaper -> `show_channel("news")`, kettle -> `next_day()`.
2. Menu: `_build_menu()` creates `menu = UiMenu.new()`, `menu.name = "Menu"`, adds it to `ui()`, connects `menu.chosen` to `_on_menu_chosen(index: int)`, then `_open_menu()`. `_open_menu()` = `menu.open(MENU_ITEMS, R_MENU.position)`. `_on_menu_chosen(index)`: 0 -> `go_garage()`, 1 -> `go_auction()`, 2 -> `next_day()`, 3 -> `open_settings()`; then ALWAYS `_open_menu()` again (UiMenu closes itself on a choice; this menu stays on screen). All four items stay enabled (the auction one explains itself with a toast).
3. Actions (public, so tests and keys can call them): `go_garage()` emits `request_scene(&"garage", {})`. `go_auction()`: if `_is_auction_day()` emit `request_scene(&"auction", {})`, else emit `toast("Auction day is the 24th of every month")`. `open_settings()` emits `request_scene(&"settings", {"overlay": true})`. `next_day()`: `get_game().act("wait_day")` (the Game toasts a refusal itself and emits `day_advanced` on success; the Flow shows the news, the office only refreshes). Calendar tap: `toast(CoreFormat.date_text(day) + " - " + str(365 - day) + " days left")` for day 1..365 (otherwise toast "The year is over").
4. TV: `_setup_tv()`: `var tv := get_node_or_null("Props/Tv")`; if it has the method `setup`, call `tv.setup(get_game())`; if it has the signal `closed` connect it to `_on_tv_closed`. `show_channel(channel: String)`: if the TV has `tune` call `tv.tune(channel)`, else emit `toast("The telly is not plugged in yet")`. `show_news()`: `_news_open = true`; if the TV has `tune` call `tv.tune("news")`, else emit `toast("The telly is not plugged in yet")` AND emit `news_closed` at once (so the Flow never waits for a news that cannot show). `_on_tv_closed()`: if `_news_open` then `_news_open = false` and emit `news_closed`.
5. `_is_auction_day() -> bool` = `CoreClock.is_auction_day(int(state.day))`. `refresh()`: `hotspots[&"phone"].set_glow(requests.size() > 0)`; `hotspots[&"poster"].set_glow(_is_auction_day())`; `placeholder("Characters").get_node("Mark").set_meta("mood", OfficeChat.mood_for(state))` (the art cards read this meta to pick a sprite). `say_today()`: if `state.day != _chat_day` then `_chat_day = state.day` and `chatter.emit(OfficeChat.line_for(state))`. `enter(_params)` calls `refresh()` and `say_today()`. `_connect_game()`: `var g = get_game()`; if not null connect `g.day_advanced` to `_on_day_advanced` (refresh + say_today) and `g.changed` to `refresh`; `_exit_tree` disconnects them when still connected. `state` is a helper getter (`get_game().state`).
6. Keys (Mac window): `handle_key(keycode: int) -> bool`: KEY_G `go_garage()`, KEY_K `next_day()`, KEY_A `go_auction()` only on an auction day, KEY_P `show_channel("bookings")`, KEY_N `show_channel("news")`; returns true when handled; `_unhandled_key_input` calls it for pressed `InputEventKey` (when visible).
7. `godot/tests/test_office_behaviour.gd` with `TestFakeGame` (set `room.game` before adding to the tree). Collect signals: `var reqs := []; room.request_scene.connect(func(i, p): reqs.append([i, p]))`, same for `toast`, `chatter`, `news_closed`. Check: the six hotspot ids exist in `room.hotspots` and no two hotspot rects intersect (`Rect2.intersects`); every hotspot is at least 64x64 and enclosed by `Rect2(0, 120, 1280, 470)`; `menu` is a visible UiMenu at `OfficeRoom.R_MENU.position` with size (280, 272).
