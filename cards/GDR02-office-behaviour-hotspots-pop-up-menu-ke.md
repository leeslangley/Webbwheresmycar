## Steps
1. Edit `godot/scenes/office.gd` (keep GDR01's constants and `_ready` start). Add `signal news_closed`, `var menu: RoomMenu`, `var _chat_day := -1`. At the end of `_ready` call `_build_hotspots()`, `_build_menu()`, `_connect_game()`, `refresh()`. `_build_hotspots()` uses `add_hotspot(id, rect)` for exactly: `&"garage_door"` R_GARAGE_DOOR, `&"poster"` R_POSTER, `&"calendar"` R_CALENDAR, `&"phone"` R_PHONE, `&"newspaper"` R_NEWSPAPER, `&"kettle"` R_KETTLE. (No TV hotspot: the TV owns its own remote buttons.) Override `_on_hotspot(id)` with a `match`: garage_door -> `go_garage()`, poster -> `go_auction()`, calendar -> toast, phone -> `show_channel("bookings")`, newspaper -> `show_channel("news")`, kettle -> `next_day()`.
2. Menu: `_build_menu()` creates `menu = RoomMenu.new()`, `menu.name = "Menu"`, `menu.setup([{"id":"garage","label":"GARAGE"},{"id":"auction","label":"AUCTION"},{"id":"next_day","label":"NEXT DAY"},{"id":"settings","label":"SETTINGS"}], R_MENU.size.x)`, `menu.position = R_MENU.position`, added to `Ui`; connect `menu.chosen` to `_on_menu_chosen(id)` which maps garage -> `go_garage()`, auction -> `go_auction()`, next_day -> `next_day()`, settings -> `open_settings()`. All four items stay enabled.
3. Actions (public, so tests and keys can call them): `go_garage()` emits `request_scene(&"garage", {})`. `go_auction()`: if `_is_auction_day()` emit `request_scene(&"auction", {})`, else emit `toast("Auction day is the 24th of every month")`. `open_settings()` emits `request_scene(&"settings", {"overlay": true})`. `next_day()`: `var r = get_game().act("advance")`; if `r is Dictionary and r.get("ok", true) == false and String(r.get("msg", "")) != ""` emit `toast(r.msg)` (the Game itself emits `day_advanced`; the Flow saves and shows the news, the office only refreshes). Calendar tap: emit `toast(CoreFormat.date_text(day) + " - " + str(365 - day) + " days left")` for day 1..365 (otherwise toast "The year is over"). `show_channel(channel: String)`: `var tv := get_node_or_null("Props/Tv")`; if `tv != null and tv.has_method("show_channel")` call `tv.show_channel(channel)` else emit `toast("The telly is not plugged in yet")`. `show_news()`: if the TV has `show_channel` call `tv.show_channel("news")`; otherwise (no usable TV) emit `toast("The telly is not plugged in yet")` AND emit `news_closed` at once, so the Flow never waits for a news that cannot show. In `_ready`, if the TV has a signal `channel_closed` connect it to `_on_channel_closed(name)` which emits `news_closed` when `name == "news"`.
4. `_is_auction_day() -> bool`: day in 1..365 and `CoreClock.is_auction_day(day)`. `refresh()`: `hotspots[&"phone"].set_glow(requests.size() > 0)`; `hotspots[&"poster"].set_glow(_is_auction_day())`; `placeholder("Characters").get_node("Mark").set_meta("mood", OfficeChat.mood_for(state))` (the art cards read this meta to pick a sprite). `say_today()`: if `state.day != _chat_day` then `_chat_day = state.day` and `chatter.emit(OfficeChat.line_for(state))`. `enter(_params)` calls `refresh()` and `say_today()`. `_connect_game()`: `var g = get_game()`; if not null connect `g.day_advanced` to `_on_day_advanced` (refresh + say_today) and `g.changed` to `refresh`; in `_exit_tree` disconnect them when still connected. `state` is a helper getter `get_game().state`.
5. Keys (Mac window): `handle_key(keycode: int) -> bool`: KEY_G `go_garage()`, KEY_K `next_day()`, KEY_A `go_auction()` only on an auction day, KEY_P `show_channel("bookings")`, KEY_N `show_channel("news")`; returns true when handled; `_unhandled_key_input` calls it for pressed `InputEventKey` (when visible).
6. `godot/tests/test_office_behaviour.gd` with `FakeGame`: build the office (instantiate, `room.game = fake`, add to tree).
