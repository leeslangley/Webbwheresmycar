## Steps
1. `godot/tv/bookings_math.gd`: `class_name BookingsMath`, `extends RefCounted`, static. `static func eff_d(model: Dictionary, car: Dictionary) -> float: return float(model.desirability) * (0.40 + 0.06 * float(car.condition))`. `static func eff_r(model: Dictionary, car: Dictionary) -> float: return float(model.reliability) * (0.30 + 0.07 * float(car.condition))`. `static func block_reason(st: Dictionary, car: Dictionary, req: Dictionary, model: Dictionary) -> String` (`""` = fine), in this order: `car.fault != null` -> `"FAULT"`; `int(car.impoundedUntil) > int(st.day)` -> `"IMPOUNDED"`; `model.is_empty()` -> `"FAULT"`; then only when `req` is not empty: `eff_d(model, car) < float(req.minDesirability)` -> `"TOO PLAIN"`; `eff_r(...) < float(req.minReliability)` -> `"TOO FLAKY"`; `float(car.condition) < float(req.minCondition)` -> `"TOO SCRUFFY"`. `static func owned_cars(st: Dictionary, models: Dictionary) -> Array`: the cars with `owned == true` whose `modelId` is a key of `models` (order kept). `static func days_left(st: Dictionary, req: Dictionary) -> int: return int(req.expiresDay) - int(st.day)`.
2. `godot/tv/bookings_channel.tscn` (text scene, exactly: `[gd_scene load_steps=2 format=3]`, blank line, `[ext_resource type="Script" path="res://tv/bookings_channel.gd" id="1"]`, blank line, `[node name="BookingsChannel" type="Control"]`, then `script = ExtResource("1")`)

Consts `PER_PAGE := 3`. `_ready()` creates `Requests` (`UiList` at `Rect2(8, 48, 300, 248)`, `row_h = 72`, `row_painter = _paint_req_row`, `row_tapped` -> `_on_req`), `PrevBtn` (`UiButton`, text "<", `Rect2(8, 300, 72, 72)`), `NextBtn` (text ">", `Rect2(560, 300, 72, 72)`), and three car slot buttons `Car0`, `Car1`, `Car2` (`UiButton`, kind "card", `role = "caption"`, rects `Rect2(88, 300, 150, 72)`, `Rect2(244, 300, 150, 72)`, `Rect2(400, 300, 150, 72)`). `PrevBtn`/`NextBtn` `activated` call `page_cars(-1)` / `page_cars(1)`; every car slot's `activated` AND `blocked` call `_on_car(slot_index)`. `func requests() -> Array: return state().get("requests", [])`. `func cars() -> Array: return BookingsMath.owned_cars(state(), ChannelBase.models_by_id())`. `func req_by_id(id: String) -> Dictionary` and `func car_by_id(id: String) -> Dictionary` (linear scans, `{}` when unknown). `func _on_req(i: int) -> void: sel_req = str(requests()[i].id); refresh()`. `func page_cars(d: int) -> void`: `var pages := maxi(1, int(ceil(cars().size() / 3.0)))`; `car_page = clampi(car_page + d, 0, pages - 1)`; `refresh()`.
