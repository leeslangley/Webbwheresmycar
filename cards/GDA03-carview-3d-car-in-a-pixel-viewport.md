## Goal
`CarView` is the one node that shows a car: a SubViewport with an orthographic camera, a key light and a rim light, the car glb loaded by id, rendered at 1/3 size and scaled up with the nearest filter (the pixel look). Paint colour, wear 0..3 and view are set from code. This replaces the old car sprites everywhere (TV shop, garage, auction, diary, HUD portrait).

## Read first
- docs/GODOT.md (plan, Compatibility renderer, pixel look, card rules)
- Car model contract (GDA01/GDA02): `res://art/cars/<id>.glb` has one MeshInstance3D node per part named `<class>_<NN>` (class is one of paint, paint2, chrome, glass, lamp, tail, trim, tyre, wall; NN two digits) and each mesh surface has a material whose `resource_name` is exactly the class. Axes in Godot: the car faces +X, up is +Y, the near (screen) side is +Z, the model is built 10.0 m long whatever the real car (1 car unit = 0.1 m); the real length is `len_mm` in `res://art/cars/manifest.json`, so the in-game scale of a car is `len_mm / 10000.0`.
- godot/art/cars/manifest.json (GDA02: per car `file`, `game_name`, `len_mm`, `bbox_min`, `bbox_max`, `paint2`)
- godot/art/car_mats.gd and wear.gd (`CarMats.make(cls, paint, wear, ground_y, body_h)`, `Wear.clamp_level`)
- docs/art/CARS_ALIGN.md section on views (side view is THE default; front is the HUD face)
- Test rule: tests never need a running SceneTree. ## Steps
1. `godot/art/carview.tscn`: exactly `[gd_scene load_steps=2 format=3]`, `[ext_resource type="Script" path="res://art/carview.gd" id="1"]`, `[node name="CarView" type="Control"]` with properties `custom_minimum_size = Vector2(480, 240)`, `layout_mode = 3`, `anchors_preset = 0`, `script = ExtResource("1")`. Nothing else: `build()` creates the children.
2. `godot/art/carview.gd`: `class_name CarView`, `extends Control`. Consts: `CARS_DIR := "res://art/cars/"`, `TURN_SPEED := 0.6` (rad per second), `TARGET := Vector3(0.0, 0.75, 0.0)`, `DIST := 30.0`, `VIEWS := {"side": {"yaw": 0.0, "pitch": 3.0, "size": 3.2, "shrink": 3}, "three_quarter": {"yaw": 35.0, "pitch": 12.0, "size": 3.6, "shrink": 3}, "front": {"yaw": 90.0, "pitch": 4.0, "size": 2.4, "shrink": 3}, "mini": {"yaw": 0.0, "pitch": 3.0, "size": 3.6, "shrink": 2}}`. `@export var default_car := ""`. Vars: `car_id := ""`, `paint := Color("c96f32")`, `wear := 0.0`, `view := "side"`. `static var _manifest: Dictionary`; `static func manifest() -> Dictionary` loads and caches `res://art/cars/manifest.json` with FileAccess and JSON (returns `{}` if missing).
3. `build()` (idempotent: returns at once if node `Box` exists) creates this exact tree: `Box` (SubViewportContainer: `stretch = true`, `stretch_shrink = 3`, `texture_filter = CanvasItem.TEXTURE_FILTER_NEAREST`, `mouse_filter = Control.MOUSE_FILTER_IGNORE`, anchors full rect via `set_anchors_preset(Control.PRESET_FULL_RECT)`) > `VP` (SubViewport: `transparent_bg = true`, `own_world_3d = true`, `msaa_3d = Viewport.MSAA_DISABLED`, `render_target_update_mode = SubViewport.UPDATE_ALWAYS`) with children `Env` (WorldEnvironment with an Environment: `background_mode = Environment.BG_CLEAR_COLOR`, `ambient_light_source = Environment.AMBIENT_SOURCE_COLOR`, `ambient_light_color = Color("6e6a8c")`, `ambient_light_energy = 0.9`), `Rig` (Node3D) with children `Cam` (Camera3D: `projection = Camera3D.PROJECTION_ORTHOGONAL`, `near = 0.05`, `far = 100.0`), `Key` (DirectionalLight3D: `rotation_degrees = Vector3(-45, -35, 0)`, `light_color = Color("fff2e0")`, `light_energy = 1.2`, `shadow_enabled = true`) and `Rim` (DirectionalLight3D: `rotation_degrees = Vector3(-20, 150, 0)`, `light_color = Color("a8c4ff")`, `light_energy = 0.7`); and `Pivot` (Node3D) with child `Blob` (MeshInstance3D: a `PlaneMesh` of size (1.0, 1.0) at y 0.01 with a `StandardMaterial3D`: `shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED`, `transparency = BaseMaterial3D.TRANSPARENCY_ALPHA`, `albedo_texture` = a `GradientTexture2D` (fill `Fill.FILL_RADIAL`, fill_from (0.5, 0.5), fill_to (1.0, 0.5), width 64, height 64, gradient from `Color(0,0,0,0.55)` at 0.0 to `Color(0,0,0,0)` at 1.0), `cast_shadow = GeometryInstance3D.SHADOW_CASTING_SETTING_OFF`). At the end `set_view("side")`. `_ready()` calls `build()` and, when `default_car != ""`, `set_car(default_car)`.
4. `set_view(v: String) -> bool`: false (nothing changes) for an unknown name. Otherwise store `view`, set `Rig.rotation_degrees.y = yaw`, `Cam.size = size`, `Box.stretch_shrink = shrink`, and `Cam.transform = Transform3D(Basis(), TARGET + DIST * Vector3(0.0, sin(pitch_rad), cos(pitch_rad))).looking_at(TARGET, Vector3.UP)` (Rig-local space). Return true.
5. `set_car(id: String) -> bool`: `m = manifest().get("cars", {})`; unknown id or glb that fails to load as PackedScene: return false and change nothing. Otherwise free the old node `Car` (if any, `free()` immediately), `inst = scene.instantiate()`, `inst.name = "Car"`, `Pivot.add_child(inst)`; `s := float(len_mm) / 10000.0`; `inst.scale = Vector3(s, s, s)`; `bmin`/`bmax` from the manifest as Vector3; `inst.position = Vector3(-(bmin.x + bmax.x) * 0.5 * s, -bmin.y * s, -(bmin.z + bmax.z) * 0.5 * s)` (ground at y 0, centred, so the turntable spins round the middle). Scan all MeshInstance3D below `inst` and store a list of {mesh_instance, surface_index, cls} with `cls` = `mesh.surface_get_material(i).resource_name` when it is one of `CarMats.CLASSES`, else the node name before the first underscore if that is a class, else `trim`. Store `_ground := bmin.y`, `_body_h := bmax.y - bmin.y`. Resize `Blob`: `(bmax.x - bmin.x) * s * 1.15` by `(bmax.z - bmin.z) * s * 1.5` (PlaneMesh.size = Vector2(x_size, z_size)). Set `car_id = id`, call `_apply()`, return true.
6. `_apply()`: for every stored surface call `mi.set_surface_override_material(i, CarMats.make(cls, col, wear, _ground, _body_h))` where `col` = `paint` for class paint, the manifest `paint2` colour (`Color(hex)`, or `paint` when the manifest string is empty) for class paint2, and `paint` (unused) for the others. `set_paint(c: Color)` stores and calls `_apply()`. `set_wear(w: float)` stores `Wear.clamp_level(w)` and calls `_apply()`. Both do nothing harmful when no car is set.
7. `turntable(on: bool)`: `set_process(on)`. `_process(delta)`: `Pivot.rotation.y += TURN_SPEED * delta`. Also in `build()` call `set_process(false)`. Helpers for tests and other cards: `get_texture() -> Texture2D` (returns `VP.get_texture()`), `car_node() -> Node3D` (the `Car` node or null), `surface_classes() -> Dictionary` ({class: surface count}), `paint_materials() -> Array` (the materials currently set on paint and paint2 surfaces), `ground_y_px() -> float` = `size.y * 0.5 + 0.75 * cos(deg_to_rad(pitch)) * size.y / Cam.size` (the screen row of the ground under the car centre, from the current view's pitch).
8. `godot/art/previews/carview_demo.tscn`: a hand-written scene: root `Control` named `Demo` (full rect, 1280x720), a `ColorRect` `Back` full rect colour `2b2550`, and an instance of `res://art/carview.tscn` named `CarView` with `layout_mode = 0`, `offset_left = 160.0`, `offset_top = 100.0`, `offset_right = 1120.0`, `offset_bottom = 580.0` and `default_car = "t1_chimp"` set on the instance (an `[ext_resource type="PackedScene" ...]` plus `[node name="CarView" parent="." instance=ExtResource("2")]`).
