# Webb, where's my car?

A comedy classic-car-hire management game, heavily inspired by *Rock Star Ate My Hamster* (Codemasters, 1989). You are Mark Webb, boss of Webb's Wheels. Buy or rent classic cars, advertise (gamble!), serve silly customers, survive the monthly auction and win four Gold Number Plates in one year. Every action costs a day.

Plays in any desktop browser and on iPhone (landscape; Add to Home Screen).

- Design: [docs/DESIGN.md](docs/DESIGN.md)
- Plan and job cards: [docs/PLAN.md](docs/PLAN.md), [cards/](cards/)
- Run tests: `make test` (macOS, uses the built-in JavaScriptCore `jsc`)
- Run in a browser: `make serve`, then open http://127.0.0.1:8000/

Fonts: Press Start 2P and VT323 (SIL Open Font License, see assets/fonts).
